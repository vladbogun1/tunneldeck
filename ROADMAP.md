# TunnelDeck — Roadmap & Ideas (внутренний, локальный)

_Черновик планов. Не для публикации. Обновляем по ходу._

## Где мы сейчас (v1.1.0, в main)
- Per-app + per-site VPN: sing-box в режиме локального прокси + ProxiFyre (перехват выбранных процессов через Windows Packet Filter). Маршруты системы не трогаются → игры и прочие приложения не рвутся при вкл/выкл.
- UI Windows 11 (светлый, RU), статус-рамка в трее (зелёная/жёлтая/красная), общая скорость туннеля, авто-детект браузеров, установщик с драйвером и ярлыками, single-file exe.
- Ядро: sing-box 1.11.15, VLESS+Reality, DoH-DNS с анти-leak, подписка с обходом Happ-lock (UA `Happ/x` + `x-hwid`).

## Текущие ограничения — и насколько реально убрать

| Ограничение | Почему так | Можно убрать? | Оценка |
|---|---|---|---|
| **UAC при каждом запуске** | app требует админа (драйвер/перехват) | **Да** — вынести перехват в elevated-службу, UI без прав | средне/высоко, большой выигрыш |
| **Скорость только суммарная (не по приложениям)** | sing-box видит трафик от ProxiFyre, не от приложения | Частично — показать по назначению/соединению, но не по exe | средне |
| **Нужен драйвер (не «просто exe»)** | ProxiFyre = Windows Packet Filter (NDIS) | Только полным переписыванием на WinDivert (хрупко) — не стоит | не рекомендуется |
| **SmartScreen предупреждает** | exe без доверенной подписи | **Да** — code-signing сертификат | низко (деньги/EV-cert) |
| **Краткий блип у уже-туннелируемых при добавлении сайта** | перезапуск sing-box для нового правила | **Да** — 2 независимых процесса (apps / sites) | средне |
| **Только VLESS в парсере** | писали под конкретного провайдера | **Да** — sing-box умеет vmess/trojan/ss/hysteria2/tuic | низко/средне |
| **Per-site только для установленных браузеров** | авто-детект по реестру | **Да** — ручной выбор браузера/exe | низко |
| **Windows-only, x64** | WPF + драйвер x64 | нет (архитектурно) | — |

## Идеи — ближний план (много пользы, мало/средне усилий)

- **Пинг серверов + настоящий «Автовыбор»** — измерять задержку/доступность каждого сервера, показывать бейдж пинга, выбирать реально быстрейший (сейчас «Автовыбор» = сервер провайдера).
- **Уведомления (тосты)** — «Подключено к Польша», «Ошибка», «Переподключение». Уверенность, что оно работает.
- **Кнопка «Проверить»** — показать текущий exit-IP и город + проверить, что конкретный сайт реально идёт через VPN (мини DNS/IP-leak тест внутри приложения).
- **Английская локализация UI + переводы README** (как у SoundDeck: EN/RU).
- **Авто-обновление** — проверять релизы на GitHub, качать и запускать установщик в один клик.
- **Больше протоколов** в парсере подписки: vmess, trojan, shadowsocks, hysteria2, tuic (ядро уже умеет).
- **Ручной выбор браузера** для сайта — на случай портативных/нестандартных.
- **Профили** — наборы (приложения + сайты + сервер) с быстрым переключением.

## Идеи — средний план

- **Reverse-режим** — «туннелировать всё, КРОМЕ выбранных приложений», и переключатель «полный VPN» (весь трафик).
- **Живой список соединений** — что сейчас идёт через VPN vs напрямую (по назначению), раз уж per-app скорость недоступна.
- **Учёт трафика за сессию** + простая история (суммарные ↓/↑ за сеанс/день).
- **Управление серверами** — вручную добавить `vless://`, переименовать, сортировать, бейджи пинга; несколько подписок.
- **DNS-настройки** — свой DoH, тумблер анти-leak, кастомный DNS для сайтов.
- **Импорт/экспорт правил** (приложения+сайты+настройки в файл).
- **Темы / тёмный режим** (у SoundDeck 20 тем — можно хотя бы light/dark).
- **Просмотр логов внутри приложения** (ядро + подписка + ProxiFyre в одном месте).

## Большие ставки (архитектура)

- **Elevated-служба + UI без прав** — служба Windows делает драйвер/ядро/перехват, UI общается с ней по локальному пайпу. Убирает UAC при каждом запуске, делает автозапуск тихим, надёжнее. **Самый большой выигрыш по UX.**
- **Настоящий leak-proof kill-switch** — WFP-правило, которое БЛОКИРУЕТ трафик выбранных приложений, если ядро/драйвер упали (сейчас kill-switch = авто-рестарт, есть окно утечки при падении процесса).
- **Code signing** — убрать SmartScreen (нужен сертификат, лучше EV).
- **Failover/здоровье серверов** — если сервер недоступен, автоматически следующий.
- **Полная поддержка форматов подписки** — clash/sing-box YAML, base64 v2ray, не только наш кейс.

## Трудно / скорее нет

- **Скорость по конкретному приложению** — прокси скрывает источник; максимум — по назначению/соединению.
- **Совсем без драйвера** — только WinDivert-переписывание (мини-Proxifier), хрупко и долго; ProxiFyre надёжнее.
- **Не-Windows** — вне области.

---

## Рекомендованные следующие 3 шага

1. **Пинг + настоящий Автовыбор** — заметная ежедневная польза, средне усилий.
2. **Elevated-служба + UI без прав** — убирает главную боль (UAC каждый раз) и делает автозапуск тихим.
3. **Уведомления + кнопка «Проверить exit-IP»** — уверенность, что VPN реально работает, дёшево.

_Опционально быстрым выигрышем: английская локализация + переводы README, и авто-обновление._
